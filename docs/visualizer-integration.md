# Clarion visualizer integration

Inspected September 9, 2026.

The Palmer page at https://www.palmerhomes.net/cavco-clarion-inhouse-experience embeds the manufacturer's application:

`https://design.cavcohomes.com/build-embed/18?retailer_id=220&retailer=Palmer+Mobile+Homes+Inc`

Belden uses the same original application at `https://design.cavcohomes.com/build-embed/18`, with no Palmer parameters. There is no copied Palmer page, styling, branding, or code in this project. Cavco permission was expressly provided by the owner in the task request.

## Origin and technical boundary

The HTML, option data, CSS, JavaScript, and image layers originate from `design.cavcohomes.com`. Key resources include `modules/product_orders_v1/resources/builder.js`, `builder-filters.js`, `builder-embed.css`, and `content/builder/builder-overlays/`. This is a layered-image configurator with elevation, trim, front-door, shingle, shutter, and siding controls. It is an exterior visualizer, not a room walk-through.

The client code uses `/build-img/` for server-rendered color changes and POSTs `action=save_product` to the current application URL for PDF/download configurations. The corresponding server application and rendering implementation are not present in the public source. Downloading the HTML and scripts alone would not reproduce the full tool faithfully. The implementation therefore embeds the actual app; it is not fully self-hosted and remains dependent on Cavco uptime and assets. No replacement configurator was invented.

## Replacement

`scripts/render-site.mjs` owns the single `VISUALIZER_URL` constant and renders the original application directly in an iframe. Replace this constant when the updated official tool arrives. `assets/js/visualizer.js` only handles full-screen controls. The host page is `design-visualizers.html`, generated by `scripts/render-site.mjs`. No model-page data or global UI logic depends on this app. It loads automatically when a visitor opens Design options, including without host-page JavaScript. The application is only embedded on that page, so its assets are not loaded on the rest of the site.

Browser testing verified initial application load and image availability with no page errors, and selection of siding controls at desktop and 390-pixel mobile widths. The mobile application's content width remained within its frame. Retailer-specific inquiry workflows are not wired through the visualizer. The Belden inquiry form is independent.

The image-layer test confirmed that selecting Market Square Regatta Blue changes the rendered siding. The PDF action on the original default configuration did not proceed: the application reported `One Shake Required - Exterior` and `One Vertical Siding Required - Exterior` before sending its save request. The same validation failure was reproduced with Palmer's exact retailer parameters. This is an original-app validation limitation, not a successful PDF export. The source application has been retained without modifying its rules. PDF export needs Cavco confirmation before it can be presented as verified.
