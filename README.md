# Belden Homes Inc. Website Rebuild

Modern static first-pass rebuild for Belden Homes Inc.

## Structure
- `index.html` — homepage
- `inventory.html` — current inventory
- `homes/` — individual model pages
- `docs/old-site-content-reference.md` — preserved legacy WordPress content
- `data/inventory.json` — structured inventory data

## Local preview
```bash
python3 -m http.server 4173
```
Then open http://localhost:4173.
